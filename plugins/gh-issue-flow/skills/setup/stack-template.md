# Stack doc skeleton

`setup` copies this to `.claude/workflow/stacks/<name>.md` in the repo and fills it from
what it probed. **The section headers are the contract**: skills read them by name, so
keep every `##` exactly as written even when a section holds only `UNVERIFIED`.

Every line under a header is one of two kinds, and says which:

- **PROBED** — a fact read from the repo, with the source path and the date.
- **UNVERIFIED — fill in** — nothing in the repo answered it. A human writes it. Skills
  treat it as an unknown and say so; they never treat it as "nothing to worry about".

Nothing is ever invented to fill a line. An honest `UNVERIFIED` is the point.
